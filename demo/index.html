Linux kernel module · out-of-tree · GPL-2.0

chardev/

A character device that works as a message queue. Each write() stores one message in a kernel buffer, each read() returns the oldest one whole, and a single mutex keeps concurrent callers from corrupting it.

rmmod undoes these in reverse. If a step fails during load, only the steps before it are undone.

      

    

  


  
  

    

      Verification
      
What the test suite checks

      
user/chardev_test.c prints PASS or FAIL for each of these, then scripts/run_tests.sh runs it again under valgrind and prints the kernel log.

    

    

      
Write then read back in orderThree messages come back byte for byte, oldest first.

      
Read on empty queueReturns 0, so cat stops cleanly.

      
ioctl GET_COUNTFive writes report a count of five.

      
ioctl CLEARCount drops to zero and nothing can be read.

      
Invalid sizes and pointersEINVAL, EMSGSIZE and EFAULT, and a message survives a too-small read.

      
Bad ioctl argumentsENOTTY for an unknown command, EFAULT for a NULL argument.

      
Buffer fullENOSPC after 15 messages of 256 bytes.

      
Concurrent readers and writers4 + 4 threads move 8,000 messages with none torn, duplicated or lost.

      
/proc stats matchopen_count and bytes_written grow by exactly what the test did.

      
CloseEvery close() return value is checked.
